# [GPAMe]([url](https://shivanshshalabh.github.io/GPAMe/)) | UB Unofficial Transcript Parser & GPA Calculator

**GPAMe** is an unofficial GPA Calculator for **University at Buffalo** students. It helps students visualize their academic progress, parse unofficial transcripts, and plan future semesters with ease.

### 🔒 Privacy First: Your Data Stays With You
Privacy and security are top priorities. **No transcript data is ever transmitted, stored, or uploaded to any server.** 
- All PDF parsing happens entirely within your web browser.
- Your data stays on your local machine and is only persisted in your browser's local storage for your convenience.
- You can clear your data anytime by clicking the "Delete Data" button in the top-right menu or by clearing your browser's site data.

## ⚠️ Important Disclaimer & Academic Integrity

**This tool is NOT affiliated with the University at Buffalo (UB) or any of its departments.** It is an independent, unofficial project meant for informational and planning purposes only.

### Use at Your Own Risk
*   **Official Accuracy**: Always refer to the official **HUB Student Center** or your **Academic Advisement Report (AAR)** for your official GPA and graduation progress.
*   **Critical Decisions**: Do **not** use this tool to make critical academic decisions regarding your scholarship eligibility, academic standing (e.g., academic dismissal), or graduation clearance.
*   **Advisor Consultation**: Please contact your **Academic Advisor** for authoritative guidance on your degree requirements and academic status.

### Ethical Intent
The intention of this project is to provide a helpful visualization tool, **not** to create a system that could potentially misguide students. We strongly request that contributors and forks refrain from modifying this tool in a way that could jeopardize a student's scholarship, graduation timeline, or visa status. Academic success is a serious matter; use this tool as a supplement, never a replacement for official university advisement. THESE UNOFFICIAL TOOLS ARE NEVER 100% ACCURATE AS THERE ARE ALWAYS EDGE CASES TO CONSIDER.

## 🚀 Features

- 📄 **Transcript Parsing**: Upload your University at Buffalo Unofficial Transcript (PDF) to instantly populate your course history.
- 📊 **GPA Visualization**: View your cumulative GPA based on official grading scales.
- 🗺️ **Course Flowsheet**: A visual map of your academic journey, categorized by "Taken", "In Progress", "Failed", and "Planned" courses.
- 📅 **Future Planning**: Add planned courses for upcoming semesters to see how they impact your path to graduation.
- 🌓 **Modern UI**: Theme-aware interface (Light/Dark mode) with a professional bluish aesthetic.

## 💻 Local Development

1.  Clone the repo:
    ```bash
    git clone https://github.com/ShivanshShalabh/GPAMe.git
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Start the development server:
    ```bash
    npm run dev
    ```
